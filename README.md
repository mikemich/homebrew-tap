# mikemich/tap

Homebrew formulae by [@mikemich](https://github.com/mikemich).

```bash
brew install mikemich/tap/appsassin
```

| Formula | Description |
|---|---|
| [appsassin](https://github.com/mikemich/appsassin) | Find and kill forgotten apps and stray processes on macOS |

`Formula/appsassin.rb` is bumped automatically by appsassin's release workflow.
